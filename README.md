# web-practice

연습 — 2026 KBO 플레이오프 **삼성 vs KIA** 경기 예측·결과 기록장.

경기마다 내 예측과 실제 결과를 기록하고, 쌓인 기록으로 다음 경기 승부를 예측합니다.

## 사용법

`index.html`을 브라우저로 열면 됩니다. 빌드나 설치는 필요 없습니다.

- **다음 경기 예측**: 기록을 바탕으로 승리 확률, 예상 스코어, 시리즈 승리 확률을 보여줍니다.
- **경기 기록**: 차전, 날짜, 홈팀, 선발, 내 예측(승리팀·스코어), 실제 결과, 메모를 저장합니다. 결과 칸을 비우면 경기 전으로 저장됩니다.
- **예측 성적**: 내 예측과 모델 예측의 적중률을 비교합니다.
- **공식 기록**: 일정·선발·결과는 `data/games.js`에 있고, 매일 아침 예약 작업이 갱신합니다 (절차는 `CLAUDE.md`).
- **내 기록**: 앱에서 입력한 예측과 메모는 브라우저(localStorage)에 저장되니 JSON 내보내기로 백업하세요.
  `data/games.js`의 `myPick`/`myScore`에 적어 둔 예측은 모든 기기에서 보입니다 (브라우저에 입력한 예측이 있으면 그쪽이 우선).

## 예측 방식 (`predict.js`)

삼성 승리 확률을 세 가지 지표로 구해 로짓 공간에서 가중 평균하고, 홈 이점을 더합니다.

| 지표 | 가중치 | 내용 |
|---|---|---|
| 상대 전적 | 0.35 | 시리즈 승패 |
| 득실점 | 0.40 | 피타고리안 승률 (지수 1.83) |
| 최근 흐름 | 0.25 | 최근 3경기, 가까운 경기일수록 크게 |
| 홈 이점 | — | 약 +3%p |

기록이 적을 때 한쪽으로 쏠리지 않도록 50:50 가상 경기 2개(팀당 4.5점)를 섞어 계산합니다.
모델 적중률은 각 경기를 그 이전 경기 기록만으로 예측한 결과로 매깁니다.
